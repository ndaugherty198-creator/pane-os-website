FAQ

Questions, answered

Is Pane OS Windows?

No. Pane OS is a Linux operating system. Pane OS is built on AnduinOS 2.0, which is based on Ubuntu. It's designed to look and work like the Windows 11 desktop, but it's an independent project and contains no Microsoft software.

Can I run Windows programs?

Many Windows programs run with the built-in Windows EXE Runner or Bottles from the Store. For most everyday tasks — browsing, office documents, photos, music and video — there are free native apps in the Store.

Does it cost anything?

No. Pane OS is free to download, use and install on as many PCs as you like. There are no ads, subscriptions or accounts.

Can I try it without installing?

Yes. Start your PC from the USB stick and Pane OS runs live from it. Nothing is changed on your PC until you run Pane OS Setup.

How do updates work?

Settings › Pane OS Update installs new versions of Pane OS apps. Ubuntu security and app updates install alongside them, and Pane OS keeps its own look and changes in place after each update.

Can I keep Windows and install Pane OS next to it?

Pane OS Setup can install alongside an existing system if your disk has free space. Always back up your files before installing any operating system.
